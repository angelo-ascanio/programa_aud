# `+ Auditoría` Button
When click, a pop up appears with a 3 phases process:
1st Phase: Options to choice `Conglomerado` or/and organization directly (if we choice a `Conglomerado` the organizations update). But the idea is to pick up a `Conglomerado` record.
2nd Phase: The `Vínculo`, this phase is optionally, if the selected `Conglomerado` have more than one `Vínculo` on it, then we must select which one, but we only have 1 `Vínculo` then it gets selected automatically. If not `Vínculo` exist yet in that `Conglomerado`, then a message that tells if we have to set a `Vínculo` for any existing certificate, or if we need to create a certificate for that organization/`conglomerado`.
3rd Phase: For each certificate that exist in that `Vínculo`, we must choice a type of audit (`Seguimiento 1`, `Renovación`, etc).
When saved it gets created the amount of audits related to all those certificates, and they are like together.
Those linked audits are together for the whole `2. Designación` Section.
